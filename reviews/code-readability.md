# Code review, readability lens: poster-tiler

Verdict: readable and well structured (pure math in tile.js, PDF in pdf.js, UI in Tool.astro), and every number in the article tables, worked example and banner tip matches the code; but one FAQ claim is false, a few comments and terms mislead, and the PDF map page ignores the chosen unit. 0 must-fix, 5 should-fix, 7 nice.

Known template leftovers (README is still the template README and mentions a `favicon.svg.ts` that does not exist, new-tool.sh, screenshots, duplicate legal links, build-date "Last updated", British spelling): not repeated below.

Recomputed by hand and with `layout()`: sheets table (18x24, 24x36, 27x40, 36x48, portrait and landscape, Letter and A4), width table (2 to 6 pages across, in and cm), worked example (4 x 4 = 16, landscape 3 x 5 = 15), banner tip (8 in on landscape Letter gives 3 x 1), dpi examples (4000 px / 24 in = 167, 3600 / 24 = 150). All correct.
