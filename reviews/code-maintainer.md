# Code review, maintainer lens: poster-tiler

Verdict: sound core. The tiling math is correct and the PDF placement is right, but 2 must-fix items remain (phone-photo orientation risk and a false offline claim on the site). Must-fix count: 2.

Checked: `npm test` passes. I recomputed all 12 table cells in the article (sheets for 4 poster sizes, portrait and landscape, Letter and A4) and all 10 "pages across" widths with `layout()`. All are correct. I also checked the image-to-tile coordinates in `pdf.js` by hand (tile N shows the right crop). Edge cases checked: exact fit, 1x1, 1.5 pages across, NaN margin, Infinity size, 10000x1 image. All behave. No HTML injection path: every `innerHTML` value is a number, a tile label or a blob URL; file names go through `textContent`.

Known template leftovers (already on the fixer's list): template README, new-tool.sh, tracked screenshots, duplicate legal links, build-date "Last updated", British spelling.
